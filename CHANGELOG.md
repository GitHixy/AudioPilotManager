# Changelog

## 1.1.0 — 2026-09-29

- Updates: a daily check for new releases on GitHub (can be turned off), a tray notification when one is out, and one-click install from Settings. Downloads are verified against the release's SHA-256 checksums; the installed version updates through Setup, the portable one replaces its own .exe.

## 1.0.0 — 2026-09-28

First release.

- Live per-app mixer: apps appear and disappear in real time, grouped per executable, with fader, dB level meter with peak hold, mute and solo.
- Mixer for any device, including microphones, with a master strip.
- Devices page: volume, mute and meter for every output and input; per-channel volume and stereo balance; make default (or default for calls only).
- Remembered per-app volumes and mute states.
- Profiles: save and apply whole mixes, including the default output.
- Tray icon with a quick mixer flyout and a menu for mute, output device, profiles and exit.
- Global shortcuts (mic mute, output mute, switch output, show/hide), rebindable, with conflict detection.
- On-screen confirmations that never take focus.
- Live microphone meter (optional), running only while a window is visible.
- Fluent UI with Mica, dark/light/system themes and seven accents.
- Start with Windows (quietly in the tray), close to tray, always on top.
- Per-user installer, portable x64 and ARM64 builds, SHA-256 checksums.
